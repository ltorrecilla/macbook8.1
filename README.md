# MacBook8,1 CachyOS hardware fixes

Experimental, community-oriented tooling for the 2015 12-inch MacBook (MacBook8,1) on CachyOS.

The opt-in CPU frequency cap has been tested on one owner's MacBook. Audio, Bluetooth, and keyboard/trackpad **installers are not yet available**; those fixes require source capture and clean-install validation.

Repository documentation and scripts are being added.
